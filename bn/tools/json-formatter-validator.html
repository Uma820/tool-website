    জেএসন কোড সাজান, সিনট্যাক্স যাচাই করুন, সুন্দর ইন্ডেন্টেশন দিন এবং ত্রুটি শনাক্ত করুন ১০০% অফলাইনে।

    টিয়ার ১: ব্রাউজার নেটিভ ১০০% ব্যক্তিগত তাত্ক্ষণিক কার্যকারিতা
    Length: 0 chars Size: 0 B

    এই টুলটি কী করে এবং কীভাবে সাহায্য করে

    জেএসন ফরম্যাটার ও ভ্যালিডেটর অবিন্যস্ত বা কম্প্রেসড JSON কোডকে সুন্দর এবং পাঠযোগ্য আকারে সাজায় এবং RFC 8259 স্ট্যান্ডার্ড অনুযায়ী সিনট্যাক্স সঠিক আছে কি না তা যাচাই করে।

    ধাপে ধাপে ব্যবহারের নির্দেশিকা

    1. এডিটরে আপনার কাঁচা JSON কোড পেস্ট করুন।
    2. ইন্ডেন্ট সাইজ নির্ধারণ করুন (২ স্পেস, ৪ স্পেস, অথবা ট্যাব)।
    3. "ফরম্যাট করুন" বাটনে ক্লিক করে সুন্দরভাবে সাজান, অথবা "যাচাই করুন" দিয়ে ভুল আছে কি না দেখুন।
    4. বৈধ হলে "কপি করুন" বা "ডাউনলোড" বাটনে ক্লিক করুন।

    ব্যবহারিক প্রয়োগক্ষেত্র

    • ওয়েব API ডিবাগিং: ওয়েব সার্ভার বা মোবাইল অ্যাপের API রেসপন্স দ্রুত পড়ে বোঝার জন্য ফরম্যাট করা।
    • কনফিগারেশন ফাইল সম্পাদনা: package.json বা সেটিংস ফাইলের কাঠামোগত ত্রুটি বা মিসিং কমা শনাক্ত করা।
    • ডেটা মিনিফাই করা: নেটওয়ার্ক ডেটা কমাতে অপ্রয়োজনীয় স্পেস ও লাইন ব্রেক বাদ দেওয়া।

    বাস্তবসম্মত উদাহরণ ও ফলাফল

    ইনপুট উদাহরণ
    {"id":101,"user":"Alice","active":true}
    প্রত্যাশিত ফলাফল
    {
  "id": 101,
  "user": "Alice",
  "active": true
}

    প্রযুক্তিগত বৈশিষ্ট্য ও কাজের পদ্ধতি

    ব্রাউজারের বিল্ট-ইন JSON.parse() এবং JSON.stringify() ইঞ্জিন ব্যবহার করে। ত্রুটি হলে ঠিক কোন লাইনে ও ক্যারেক্টারে ভুল রয়েছে তা প্রদর্শন করে।

    সীমাবদ্ধতা ও ব্রাউজার সীমা

    কঠোর RFC 8259 নিয়ম প্রযোজ্য; সিঙ্গেল কোটেশন বা কমেন্ট যুক্ত থাকলে তা অবৈধ হিসেবে চিহ্নিত হবে।

    গোপনীয়তা ও নিরাপত্তার নিশ্চয়তা

    কোনো ডেটা সার্ভারে যায় না। আপনার গোপনীয় API টোকেন বা গ্রাহক ডেটা আপনার ব্রাউজারেই নিরাপদ থাকে।

    সাধারণ জিজ্ঞাস্য (FAQs)

    JSON-এ কমেন্ট ব্যবহার করা যায় কি?

    আদর্শ JSON স্ট্যান্ডার্ডে কমেন্ট সমর্থিত নয়। কমেন্ট থাকলে ফরম্যাট করার আগে তা সরিয়ে নিতে হবে।

    কেন সিঙ্গেল কোটেশনের কারণে ত্রুটি দেখায়?

    JSON স্পেসিফিকেশন অনুযায়ী সমস্ত কি (keys) এবং স্ট্রিং ডাবল কোটেশন (") দিয়ে আবদ্ধ হতে হবে।
