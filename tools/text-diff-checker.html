    User Problem & Purpose

    Proofreaders, software engineers, legal analysts, and students frequently need to compare two drafts of a contract, article, or source file to pinpoint exact additions and deletions. Comparing text line-by-line manually leads to overlooked errors. This tool computes a line-level diff highlighting exactly what was introduced, removed, or kept intact.

    Step-by-Step Instructions

    1. Paste the earlier or original version in the Original Text (Before) box.
    2. Paste the revised or new draft in the Modified Text (After) box.
    3. Choose whether to ignore case or trailing whitespace differences.
    4. Click Compare Differences (or review live changes).
    5. Examine the visual output: green (+) represents added text, and red (-) represents deleted text.

    Common Practical Use Cases

    • Code & Script Reviews: Spotting changes between configuration files (JSON, YAML, INI) or code snippets.
    • Contract & Policy Audits: Checking revised terms of service, NDA agreements, or legal agreements for changed clauses.
    • Academic Essays: Reviewing edits made between peer-review drafts or collaborative assignments.

    Technical Specifications & Mechanics

    The diff engine is implemented using the Longest Common Subsequence (LCS) dynamic programming algorithm, the same mathematical foundation behind UNIX diff and Git change trackers. It computes an edit script with minimal edit distance to display genuine modifications without misaligning surrounding paragraphs.

    Limitations & Browser Boundaries

    Extremely large documents exceeding 50,000 lines may require several seconds of CPU processing in JavaScript. For typical documents under 5,000 lines, diff computation completes in under 50 milliseconds.

    Privacy & Security Guarantee

    Both text bodies remain strictly in browser volatile memory. Zero proprietary contracts, private letters, or confidential code snippets are ever transmitted or cached on our servers.

    Frequently Asked Questions

    Does this tool compare word-by-word or line-by-line?

    This tool performs line-by-line comparisons, which is standard for documents, scripts, and code. Single lines with modifications show as a replacement (old line removed, new line added).

    Can I swap the two boxes easily?

    Yes. Click the Swap Texts button in the toolbar to reverse the comparison direction instantly.

    Are my confidential documents safe?

    Yes. The tool runs 100% client-side without any server API calls, network sockets, or external analytics.
