    What This Tool Does & Problem It Solves

    The PDF Page Counter & File Analyzer performs an instant audit of any PDF document. It extracts total page counts, file size metrics (bytes, KB, MB), PDF version, and embedded document metadata (Title, Author, Subject, Creator, Producer) without opening slow desktop viewers.

    Step-by-Step Instructions

    1. Select or drag and drop your PDF file into the inspection zone.
    2. The tool analyzes the binary header and page tree immediately.
    3. Review the summary grid: Total Page Count, Exact File Size, and PDF Version.
    4. Inspect the Metadata Audit table for embedded author, creation date, and software producer fields.

    Common Practical Use Cases

    • Printing Cost & Volume Estimation: Determine exact page counts before sending large publications or manuals to commercial print shops.
    • Academic Double-Blind Review Audits: Check whether author names or software identifiers are accidentally embedded in academic paper submissions.
    • Document Hygiene & Metadata Sanitization: Inspect the metadata dictionary of public documents before publishing to external websites.

    Technical Specifications & Mechanics

    Reads standard PDF cross-reference tables and embedded /Info dictionaries using pdf-lib. Byte counts are computed from the file object directly.

    Limitations & Browser Boundaries

    Displays embedded metadata dictionaries; does not perform OCR or deep stream decompression. Encrypted files require credentials to inspect metadata.

    Privacy & Security Guarantee

    Local client audit only. The file is analyzed entirely in browser memory and never uploaded.

    Frequently Asked Questions

    Does this tool work on password-protected PDFs?

    If a PDF has standard encryption, metadata dictionaries may be unreadable without the password.

    Can this tool read hidden metadata?

    It extracts all standard /Info dictionary fields (Title, Author, Subject, Keywords, Creator, Producer, CreationDate, ModDate).

    Does this tool upload my PDF to any server?

    No. The file is read locally using the browser FileReader API. Your document never leaves your machine.
