    What Does the URL Extractor Do?

    The URL Extractor scans text blocks, HTML documents, XML sitemaps, Markdown files, and error logs to extract all valid web links and URLs. It identifies links regardless of whether they are standalone HTTP/HTTPS addresses, embedded within anchor tags (<a href="https://example.com">), source attributes (<img src="https://example.com/image.png">), or formatted in Markdown syntax ([text](url)).

    With built-in cleaning utilities, you can easily strip query parameters (tracking UTM tags), remove hash anchors, filter by domain, or reduce a massive list of deep web links down to their primary parent domains.

    Step-by-Step Instructions

    1. Input Raw Content: Paste your unstructured text or HTML source code into the left text box, or click Sample Text to load an example.
    2. Choose Extraction Scope: Select Full URL Path to keep complete paths, Root Domain Only to pull just hostnames, or Origin to preserve protocol and host without path folders.
    3. Configure Cleaning Options: Toggle Strip query parameters to remove Google Analytics UTM tags or session IDs, and toggle Strip anchor tags to clean on-page fragment identifiers.
    4. Format & Export: Select your preferred output formatting (plain list, Markdown bullets, or HTML list items) and click Copy Result or download as .txt / .csv.

    Technical Specifications & Mechanics

    • URL Parsing: Supports standard schemes including http://, https://, ftp://, and protocol-relative // links.
    • Attribute Extraction: Automatically detects URLs nested within HTML attributes like href, src, data-src, action, and content.
    • DOM URL Validation: Employs native browser new URL() parsing for hostname decomposition, origin identification, and parameter stripping.
    • Zero Latency: Executes purely in browser memory with instant interactive updates.

    Limitations & Browser Boundaries

    Relative links that do not specify a domain or root (such as /about or ../images/pic.png) are extracted if they follow standard HTML attribute patterns, but cannot have hostnames calculated unless a base URL is present. Malformed URLs with spaces or unencoded illegal characters are sanitized or flagged.

    Privacy & Security Guarantee

    All URL extraction and analysis occurs 100% locally on your computer inside your web browser. No text, source code, internal intranet URLs, or confidential links are ever uploaded to our servers or external services.

    Frequently Asked Questions

    Can I extract links directly from HTML source code?

    Yes. Simply right-click on any webpage, select "View Page Source", copy the HTML, and paste it into the extractor. It will automatically harvest all URLs.

    What does "Strip query parameters" do?

    It deletes everything after the question mark ? in each URL. This is ideal for cleaning up marketing URLs that contain long tracking codes such as utm_source, utm_medium, or session IDs.

    How are duplicates handled when query strings differ?

    If you enable "Strip query parameters" and "Deduplicate", two URLs that point to the same page with different tracking codes (e.g. ?ref=fb vs ?ref=tw) will be cleaned first and merged into a single unique link.
